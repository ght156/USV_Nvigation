我按“视觉优先、RTK热备切换”的思路重构第一阶段：Tag可见时持续更新入口相对位姿与入口RTK；Tag丢失后不停车搜索，而是无缝切到最后锁定的RTK入口。重点会把切换条件、目标更新限幅和到入口后的重新视觉接管写清楚。

这版思路可以定下来：**第一阶段不是纯视觉，也不是纯RTK，而是“Tag可见时视觉控制并持续更新入口RTK；Tag丢失后无缝切换到最后有效入口RTK继续到达入口”**。这样既利用了AprilTag的相对定位精度，也避免后视相机因船体姿态变化丢Tag后反复搜索。

当前仓库本身已将精靠泊独立在 `src/usv_docking`，感知位于 `src/apriltag_localization`，远距离导航仍由Nav2体系负责，因此这一修改适合放在现有归港控制器内完成，不需要重新组织整个系统。([GitHub](https://github.com/ght156/USV_Nvigation))

下面是一版重新收敛后的修改方案。

# 后视相机双目标、视觉—RTK混合两阶段归港修改方案

## 一、总体目标

归港过程分成三个部分：

```text
Nav2导航到预泊点
        ↓
预泊点搜索并稳定检测AprilTag
        ↓
第一阶段：驶向动态入口
        ├── Tag可见：使用入口相对船体位姿进行视觉控制
        │           同时不断更新入口RTK
        │
        └── Tag丢失：不再搜索Tag
                    使用最后有效入口RTK继续控制到入口
        ↓
入口附近停车并重新检测Tag
        ↓
第二阶段：使用船坞中心相对船体位姿视觉倒入
        ↓
充电确认或最终距离满足
        ↓
停车
```

核心原则：

```text
第一阶段：
视觉优先，RTK热备。

第二阶段：
纯视觉闭环，持续丢Tag立即停车。
```

第一阶段不要求Tag始终处于视野内，也不要求Tag始终靠近图像中心。

------

# 二、AprilTag节点输出内容

AprilTag节点继续计算当前船坞中心相对相机或 `base_link`的位姿，同时计算入口目标相对相机或 `base_link`的位姿。

建议统一输出到 `base_link`。

## 2.1 船坞中心位姿

```text
dock_center_pose_base
```

含义：

```text
最终停靠参考中心相对base_link的位置和方向。
```

字段：

```text
center_x_base
center_y_base
center_yaw_base
```

第二阶段使用该位姿进行视觉闭环倒入。

## 2.2 入口位姿

```text
dock_entry_pose_base
```

含义：

```text
第一阶段入口目标相对base_link的位置和方向。
```

字段：

```text
entry_x_base
entry_y_base
entry_yaw_base
```

第一阶段Tag可见时直接使用该位姿进行控制。

## 2.3 入口位姿计算

假设当前AprilTag节点已经得到：

```text
base_to_dock_center
```

再配置入口相对船坞中心的固定变换：

```text
dock_center_to_entry
```

计算：

```cpp
base_to_entry =
    base_to_dock_center
    * dock_center_to_entry;
```

入口参数示例：

```yaml
entry_offset_x_dock: -3.0
entry_offset_y_dock: 0.0
entry_offset_yaw_deg: 0.0
```

具体正负号必须根据当前船坞坐标系验证。

两个目标共享同一个船坞方向：

```text
entry_yaw_base = dock_yaw_base
center_yaw_base = dock_yaw_base
```

不要为入口和中心独立估计两套yaw。

# 四、双Tag处理

第一版仍建议保留双Tag融合。

原因是入口点通常距离船坞中心数米，船坞yaw误差会被入口偏移放大。

双Tag同时可见时：

```text
位置：
    两个Tag分别推算统一船坞中心；
    进行一致性检查后加权融合。

yaw：
    优先使用两个Tag中心基线计算船坞yaw。
```

只有单Tag可见时：

```text
允许生成入口位姿；
允许第一阶段继续运行；
入口RTK继续更新；
置信度降低。
```

进入第二阶段时不一定强制要求两个Tag同时可见，但至少要满足：

```text
船坞中心位姿稳定；
yaw误差小；
相邻帧跳变小；
当前视觉观测连续有效。
```

若实测单Tag的yaw明显不稳定，再将“双Tag稳定可见”作为第二阶段启动条件。

# 五、入口RTK由归港包计算

AprilTag节点只负责输出：

```text
入口相对base_link的位姿。
```

入口的RTK坐标由 `usv_docking`计算，因为归港节点已经能够同时获得：

```text
当前RTK；
当前odom或全局航向；
入口相对base_link的位置。
```

职责划分：

```text
apriltag_localization：
    图像检测；
    Tag位姿；
    船坞中心位姿；
    入口相对位姿。

usv_docking：
    入口相对位姿转换为ENU；
    ENU转换为入口RTK；
    保存和更新动态入口；
    进行视觉与RTK控制切换。
```

# 六、入口RTK计算

设当前船的位置为：

```text
boat_east
boat_north
```

或：

```text
boat_latitude
boat_longitude
```

当前船体在ENU/map中的航向为：

```text
boat_yaw_global
```

入口在 `base_link`中的位置为：

```text
entry_x_base
entry_y_base
```

转换到ENU：

```python
entry_east_offset = (
    math.cos(boat_yaw_global) * entry_x_base
    - math.sin(boat_yaw_global) * entry_y_base
)

entry_north_offset = (
    math.sin(boat_yaw_global) * entry_x_base
    + math.cos(boat_yaw_global) * entry_y_base
)
```

然后：

```text
entry_east =
    boat_east + entry_east_offset

entry_north =
    boat_north + entry_north_offset
```

最后使用项目中已有的ENU/WGS84转换函数得到：

```text
entry_latitude
entry_longitude
```

不要在归港包中重新实现一套与现有导航系统方向定义不同的坐标转换。

# 七、入口全局方向计算

除了入口位置，还应同时更新船坞方向。

AprilTag给出的：

```text
entry_yaw_base
```

表示船坞轴线相对当前船体的角度。

船坞轴线全局方向：

```python
dock_yaw_global = normalize_angle(
    boat_yaw_global
    + entry_yaw_base
)
```

倒车时目标船体航向可能是：

```python
target_boat_yaw = dock_yaw_global
```

或：

```python
target_boat_yaw = normalize_angle(
    dock_yaw_global + math.pi
)
```

必须根据以下定义实测确认：

```text
base_link X轴方向；
船坞X轴方向；
后视相机外参；
船艉进入时船体期望朝向。
```

入口动态目标应保存：

```text
entry_latitude
entry_longitude
entry_east
entry_north
dock_yaw_global
target_boat_yaw
update_time
source_confidence
```

# 八、第一阶段的核心控制模式

第一阶段设置一个主状态：

```text
APPROACH_DYNAMIC_ENTRY
```

状态内部包含两种控制模式：

```text
VISION_ENTRY_CONTROL
RTK_ENTRY_CONTROL
```

不必把这两种模式拆成两个大的状态。

## 8.1 Tag可见时：视觉入口控制

满足以下条件时采用视觉：

```text
pose_valid == true
入口位姿消息未超时
confidence达到最低阈值
相邻帧位姿跳变没有超过阈值
```

此时：

```text
使用entry_x_base、entry_y_base、entry_yaw_base控制；
同时根据当前RTK和航向持续更新entry RTK。
```

控制目标不是保持Tag在图像中心，而是：

```text
使船到达入口目标；
使船体逐渐与船坞轴线对齐。
```

入口相对位姿控制误差：

```python
distance_error = math.hypot(
    entry_x_base,
    entry_y_base,
)

bearing_error = math.atan2(
    entry_y_base,
    entry_x_base,
)

yaw_error = normalize_angle(
    entry_yaw_base
    - back_in_target_yaw_base
)
```

由于是倒车，应根据当前控制器已验证的速度符号和航向定义调整。

建议不要直接只用：

```text
entry_y_base
```

控制角速度。

应根据距离分段融合“目标方位”和“最终船坞方向”。

距离较远时：

```text
优先朝入口目标运动。
```

接近入口时：

```text
逐渐优先对齐船坞方向。
```

简单实现：

```python
heading_weight = clamp(
    1.0 - distance_error / heading_blend_distance,
    0.0,
    1.0,
)

angular_error = normalize_angle(
    (1.0 - heading_weight) * bearing_error
    + heading_weight * yaw_error
)
```

然后：

```python
cmd_w = kp_entry_yaw * angular_error
```

线速度：

```python
cmd_v = entry_back_speed
```

根据误差降低速度：

```python
if abs(angular_error) > entry_yaw_slow_threshold:
    cmd_v *= entry_yaw_slow_scale

if abs(angular_error) > entry_yaw_stop_threshold:
    cmd_v = 0.0
```

但不以Tag是否位于图像中央作为控制约束。

------

## 8.2 Tag可见时持续更新入口RTK

每次得到有效Tag后，都计算新的入口全局坐标：

```text
new_entry_east
new_entry_north
new_dock_yaw_global
```

但不能直接每帧覆盖，否则视觉抖动会造成入口RTK跳动。

采用限幅低通更新：

```python
delta_east = (
    new_entry_east
    - self.entry_east_filtered
)

delta_north = (
    new_entry_north
    - self.entry_north_filtered
)

delta_distance = math.hypot(
    delta_east,
    delta_north,
)
```

若：

```text
delta_distance <= entry_update_accept_m
```

执行低通：

```python
self.entry_east_filtered = (
    entry_rtk_alpha * new_entry_east
    + (1.0 - entry_rtk_alpha)
    * self.entry_east_filtered
)

self.entry_north_filtered = (
    entry_rtk_alpha * new_entry_north
    + (1.0 - entry_rtk_alpha)
    * self.entry_north_filtered
)
```

yaw使用角度低通：

```python
yaw_delta = normalize_angle(
    new_dock_yaw_global
    - self.dock_yaw_global_filtered
)

self.dock_yaw_global_filtered = normalize_angle(
    self.dock_yaw_global_filtered
    + dock_yaw_alpha * yaw_delta
)
```

若入口更新跳变过大：

```text
本帧不更新入口RTK；
视觉控制也可暂时拒绝该帧；
继续使用上一有效目标；
记录告警。
```

建议参数：

```yaml
entry_rtk_alpha: 0.20
dock_yaw_global_alpha: 0.15
entry_update_accept_m: 0.50
entry_update_hard_reject_m: 1.00
entry_yaw_update_accept_deg: 12.0
```

# 九、Tag丢失后的切换逻辑

第一阶段Tag丢失后：

```text
不停车搜索；
不回到SEARCH_TAG；
不旋转寻找Tag；
不反复切换状态。
```

而是切换到：

```text
RTK_ENTRY_CONTROL
```

使用最后一个有效动态入口：

```text
locked_entry_east
locked_entry_north
locked_target_boat_yaw
```

进入RTK模式的条件：

```text
Tag消息超时；
但已经至少成功生成过一次有效入口RTK；
RTK和航向仍然有效；
动态入口数据没有超过最大允许年龄。
```

例如：

```yaml
tag_to_rtk_switch_sec: 0.25
maximum_entry_snapshot_age_sec: 30.0
```

切换时不需要制动到零，只需进行平滑控制权切换。

建议保存切换瞬间的速度命令，并对新命令限斜率：

```python
cmd_v = rate_limit(
    previous_cmd_v,
    rtk_cmd_v,
    max_linear_acceleration,
    control_dt,
)

cmd_w = rate_limit(
    previous_cmd_w,
    rtk_cmd_w,
    max_angular_acceleration,
    control_dt,
)
```

防止视觉控制和RTK控制输出方向突然跳变。

# 十、RTK入口控制

Tag丢失后，使用当前已经验证过的GNSS直线倒船框架。

建议保留：

```text
直线leg锁定；
剩余距离；
横向误差；
目标船体航向；
误差分档控制。
```

## 10.1 动态入口leg

第一次获得有效入口RTK时：

```text
保存入口目标。
```

Tag持续可见并更新入口RTK时：

```text
入口目标允许平滑移动。
```

但直线leg不建议每帧彻底重新锁定，否则直线路径方向会抖动。

可以采用：

```text
当前位置到动态入口作为当前参考线；
或每隔0.5～1.0秒更新一次leg；
入口变化很小时不重建leg。
```

推荐第一版：

```yaml
entry_leg_update_period_sec: 0.50
entry_leg_update_min_distance_m: 0.15
```

只有入口更新超过0.15米，且距上次重建超过0.5秒，才重建参考直线。

Tag丢失后：

```text
冻结入口；
冻结leg；
不再改变目标。
```

## 10.2 RTK控制误差

至少计算：

```text
remaining_distance
cross_track_error
heading_error
```

角速度：

```python
cmd_w = (
    kp_rtk_heading * heading_error
    + kp_rtk_cross_track * cross_track_error
)
```

线速度根据误差分级：

```text
heading_error较小：
    正常低速倒车。

heading_error中等：
    降低倒车速度并修正。

heading_error较大：
    停止纵向运动，只调整方向。
```

这可以继续复用现有的：

```text
pure
walk_fix
correct
```

三档控制逻辑。

# 十一、Tag重新出现后的处理

第一阶段中Tag丢失后可能再次出现。

不要看到一帧Tag就立即从RTK切回视觉。

设置连续恢复条件：

```yaml
tag_recover_cycles: 4
tag_recover_max_position_jump_m: 0.40
tag_recover_max_yaw_jump_deg: 10.0
```

Tag连续稳定后：

```text
重新计算入口RTK；
将新入口与当前锁定入口比较。
```

如果差异较小：

```text
平滑更新入口RTK；
切回VISION_ENTRY_CONTROL。
```

如果差异较大：

```text
先保持RTK控制；
累计多帧确认；
必要时减速；
确认船坞确实移动后再更新。
```

不能因为一帧错误检测造成目标突然跳转。

因此模式切换应带滞回：

```text
视觉丢失0.25秒：
    VISION → RTK。

视觉恢复连续4帧：
    RTK → VISION。
```

避免在Tag检测边缘不断来回切换。

# 十二、第一阶段不再主动搜索

搜索只在两个固定位置发生。

## 12.1 预泊点初始搜索

到达预泊点后：

```text
如果没有检测到Tag：
    使用现有SEARCH_SPIN。
```

找到并稳定检测Tag后：

```text
生成动态入口；
进入第一阶段。
```

第一阶段开始后：

```text
不再主动搜索Tag。
```

## 12.2 入口处第二次搜索

当第一阶段根据视觉或RTK判断已到达入口：

```text
停车；
等待船体稳定；
重新检测Tag。
```

如果Tag没有立即出现：

```text
允许使用现有有限范围入口搜索。
```

这里可以搜索，因为船还处于入口外或入口附近，并且下一步必须依赖视觉。

但搜索角度应受限，避免船体偏离已对准的中心线。

建议：

```yaml
entry_tag_search_max_angle_deg: 10.0
entry_tag_search_speed_rad_s: 0.05
entry_tag_search_timeout_sec: 6.0
```

若搜索失败：

```text
停车并ABORT；
不重新执行第一阶段循环。
```

# 十三、第一阶段完成判定

需要同时考虑视觉模式和RTK模式。

## 13.1 视觉模式到达入口

如果Tag可见：

```text
使用entry_pose判断位置误差；
同时使用RTK距离作为辅助。
```

完成条件：

```text
视觉入口距离小于阈值；
入口横向误差小于阈值；
船坞yaw误差小于阈值；
RTK入口距离没有明显冲突。
```

建议：

```yaml
vision_entry_distance_tolerance_m: 0.30
vision_entry_lateral_tolerance_m: 0.20
vision_entry_yaw_tolerance_deg: 6.0
rtk_visual_entry_consistency_m: 0.60
```

## 13.2 RTK模式到达入口

如果Tag已丢失：

```text
使用RTK入口距离；
使用目标船体航向误差。
```

完成条件：

```text
RTK距离小于阈值；
目标船体航向误差小于阈值；
连续稳定若干周期。
```

建议：

```yaml
rtk_entry_distance_tolerance_m: 0.35
rtk_entry_yaw_tolerance_deg: 7.0
entry_stable_sec: 0.50
```

到达后：

```text
发布零速度；
进入ENTRY_SETTLE；
不立即进入第二阶段。
```

# 十四、入口稳定与第二阶段接管

入口处执行：

```text
ENTRY_SETTLE
```

过程：

```text
停车0.5～1.0秒；
等待船体角速度下降；
重新获取Tag；
重新计算船坞中心位姿。
```

允许进入第二阶段的条件：

```text
dock_center_pose有效；
Tag连续有效；
船坞yaw误差满足要求；
船体横向误差满足要求；
当前入口位置仍位于安全区域。
```

如果入口处Tag重新检测后发现：

```text
船体横向偏差或yaw偏差较大
```

不要立即倒入。

进入：

```text
ALIGN_ENTRY
```

在入口外进行小幅调整。

调整完成后进入：

```text
BACK_IN
```

```text
AprilTag检测
    ↓
统一船坞中心位姿
    ├── dock_center_pose_base
    │       ↓
    │   第二阶段视觉倒入
    │
    └── 固定偏移
            ↓
        entry_pose_base
            ↓
        usv_docking结合RTK和yaw
            ↓
        dynamic_entry_rtk
            ↓
第一阶段控制
    ├── Tag可见
    │       ↓
    │   视觉入口控制
    │   动态入口RTK持续更新
    │
    └── Tag丢失
            ↓
        冻结最后入口RTK
            ↓
        RTK直线控制到入口
            ↓
        入口重新获取Tag
            ↓
        第二阶段视觉倒入
```

这套方案的关键不是在视觉和RTK之间二选一，而是让两者承担不同作用：

```text
AprilTag：
    提供实时、相对、精确的入口位置和船坞方向。

RTK：
    在第一阶段Tag离开后视相机视野时保持目标连续。

当前直线控制器：
    负责几米范围内的低速倒车和视觉—RTK无缝切换。

RPP：
    继续只负责远距离导航到预泊点。
```

这一版相比上一版删除了第一阶段行驶过程中的Tag搜索，也删除了第二阶段的主动恢复搜索。第一阶段Tag可见时仍充分利用视觉，不是简单锁定一次RTK；只有真正丢失后才冻结最后有效入口并转入RTK，因此既能跟随船坞的小范围变化，又不会因视野问题陷入搜索循环。



你提出的“视觉优先、RTK热备切换”思路非常务实和高效，它抓住了核心问题——利用AprilTag的相对精度进行初始对准，利用RTK的全局稳定性保证在视觉短暂失效时仍能到达入口，避免了不必要的复杂搜索和状态切换。这个方案比之前的复杂架构更易于实现和调试，能快速达到“稳定进去”的目标。

# src/usv_docking/usv_docking/docking_controller.py
class DockingController(Node):
    def __init__(self):
        # ... 初始化 ...
        self.control_mode = "IDLE"  # VISION_ENTRY, RTK_ENTRY, BACK_IN
        self.entry_rtk = None       # 存储入口RTK坐标 (east, north, yaw)
        self.entry_rtk_filtered = None # 滤波后的入口RTK
        self.last_valid_entry_time = None
        self.cmd_prev = Twist()     # 上一周期速度命令，用于平滑切换
        # 参数
        self.declare_parameter('tag_timeout_sec', 0.25)
        self.declare_parameter('entry_rtk_alpha', 0.2)
        self.declare_parameter('entry_update_accept_m', 0.5)
        self.declare_parameter('tag_recover_cycles', 4)
        self.declare_parameter('entry_back_speed', 0.05)  # 倒车速度
        self.declare_parameter('kp_entry_yaw', 0.6)
    def perception_callback(self, msg):
        """处理视觉感知消息"""
        if len(msg.data) < 10:
            return
        entry_x = msg.data[0]
        entry_y = msg.data[1]
        entry_yaw = msg.data[2]
        center_x = msg.data[3]
        center_y = msg.data[4]
        center_yaw = msg.data[5]
        confidence = msg.data[6]
        tag_count = int(msg.data[7])
        mode = int(msg.data[8])
        valid = bool(int(msg.data[9]))
        self.last_perception = {
            'entry': (entry_x, entry_y, entry_yaw),
            'center': (center_x, center_y, center_yaw),
            'confidence': confidence,
            'tag_count': tag_count,
            'mode': mode,
            'valid': valid,
            'time': self.get_clock().now()
        }
        # 如果视觉有效，更新入口RTK
        if valid and tag_count > 0:
            self.update_entry_rtk_from_vision(entry_x, entry_y, entry_yaw)
    def update_entry_rtk_from_vision(self, entry_x_base, entry_y_base, entry_yaw_base):
        """将视觉入口位姿转换为全局RTK坐标并滤波更新"""
        # 1. 获取当前船的RTK和航向
        boat_east, boat_north, boat_yaw = self.get_current_rtk_and_yaw()
        if boat_east is None:
            return
        # 2. 将base_link系下的入口位姿旋转到ENU系
        cos_yaw = math.cos(boat_yaw)
        sin_yaw = math.sin(boat_yaw)
        entry_east_offset = cos_yaw * entry_x_base - sin_yaw * entry_y_base
        entry_north_offset = sin_yaw * entry_x_base + cos_yaw * entry_y_base
        new_entry_east = boat_east + entry_east_offset
        new_entry_north = boat_north + entry_north_offset
        new_dock_yaw_global = self.normalize_angle(boat_yaw + entry_yaw_base)
        # 3. 跳变检测与低通滤波
        if self.entry_rtk_filtered is not None:
            delta_east = new_entry_east - self.entry_rtk_filtered[0]
            delta_north = new_entry_north - self.entry_rtk_filtered[1]
            delta_dist = math.hypot(delta_east, delta_north)
            if delta_dist > self.entry_update_accept_m_:
                # 跳变过大，拒绝更新
                self.get_logger().warn(f"Entry RTK jump rejected: {delta_dist:.2f}m")
                return
            # 低通滤波
            alpha = self.entry_rtk_alpha_
            filtered_east = alpha * new_entry_east + (1-alpha) * self.entry_rtk_filtered[0]
            filtered_north = alpha * new_entry_north + (1-alpha) * self.entry_rtk_filtered[1]
            # yaw需要角度滤波
            yaw_delta = self.normalize_angle(new_dock_yaw_global - self.entry_rtk_filtered[2])
            filtered_yaw = self.normalize_angle(self.entry_rtk_filtered[2] + alpha * yaw_delta)
            self.entry_rtk_filtered = (filtered_east, filtered_north, filtered_yaw)
        else:
            self.entry_rtk_filtered = (new_entry_east, new_entry_north, new_dock_yaw_global)
        self.last_valid_entry_time = self.get_clock().now()
    def control_step(self):
        """主控制循环"""
        if self.control_mode == "APPROACH_DYNAMIC_ENTRY":
            self.control_approach_entry()
        elif self.control_mode == "BACK_IN":
            self.control_back_in()

    def control_approach_entry(self):
        """第一阶段：驶向动态入口"""
        now = self.get_clock().now()
        perception_valid = (self.last_perception is not None and
                            (now - self.last_perception['time']).nanoseconds < self.tag_timeout_sec_ * 1e9)
        if perception_valid and self.last_perception['valid']:
            # 视觉控制模式
            if self.control_mode_ != "VISION_ENTRY":
                self.get_logger().info("Switching to VISION_ENTRY control")
                self.control_mode_ = "VISION_ENTRY"
            # 使用视觉入口位姿控制
            entry_x, entry_y, entry_yaw = self.last_perception['entry']
            distance_error = math.hypot(entry_x, entry_y)
            bearing_error = math.atan2(entry_y, entry_x)
            yaw_error = self.normalize_angle(entry_yaw - math.pi)  # 假设倒车，目标航向与入口yaw相反
            # 融合控制：远距离用bearing，近距离用yaw
            heading_weight = max(0.0, min(1.0, 1.0 - distance_error / 2.0))
            angular_error = self.normalize_angle(
                (1.0 - heading_weight) * bearing_error + heading_weight * yaw_error)
            cmd_v = -self.entry_back_speed_  # 倒车
            cmd_w = self.kp_entry_yaw_ * angular_error
            # 速度限幅
            cmd_v = max(-self.entry_back_speed_, min(0.0, cmd_v))  # 确保倒车
            cmd_w = max(-0.1, min(0.1, cmd_w))  # 限制角速度
        else:
            # RTK控制模式
            if self.control_mode_ != "RTK_ENTRY":
                self.get_logger().info("Switching to RTK_ENTRY control")
                self.control_mode_ = "RTK_ENTRY"
                # 切换时保存当前速度，用于平滑过渡
                self.cmd_prev_ = self.last_cmd_
            if self.entry_rtk_filtered is None:
                # 无有效入口RTK，停车
                cmd_v = 0.0
                cmd_w = 0.0
            else:
                # 计算到入口RTK的误差
                boat_east, boat_north, boat_yaw = self.get_current_rtk_and_yaw()
                dx = self.entry_rtk_filtered[0] - boat_east
                dy = self.entry_rtk_filtered[1] - boat_north
                distance = math.hypot(dx, dy)
                bearing = math.atan2(dy, dx)
                heading_error = self.normalize_angle(bearing - boat_yaw)
                # 简单RTK直线倒车控制
                cmd_v = -self.entry_back_speed_
                cmd_w = self.kp_rtk_heading_ * heading_error
                # 速度限幅
                cmd_v = max(-self.entry_back_speed_, min(0.0, cmd_v))
                cmd_w = max(-0.1, min(0.1, cmd_w))
        # 平滑速度命令（防止切换时跳变）
        cmd_v = self.rate_limit(self.cmd_prev_.linear.x, cmd_v, 0.05, 0.1)
        cmd_w = self.rate_limit(self.cmd_prev_.angular.z, cmd_w, 0.1, 0.2)
        # 发布命令
        cmd = Twist()
        cmd.linear.x = cmd_v
        cmd.angular.z = cmd_w
        self.cmd_pub.publish(cmd)
        self.cmd_prev_ = cmd
        # 检查是否到达入口
        if self.is_at_entry():
            self.control_mode_ = "ENTRY_SETTLE"
            self.settle_start_time = self.get_clock().now()
    def is_at_entry(self):
        """判断是否到达入口"""
        if self.control_mode_ == "VISION_ENTRY" and self.last_perception:
            # 视觉判断：距离入口小于0.3m，横向误差小于0.2m
            entry_x, entry_y, _ = self.last_perception['entry']
            distance = math.hypot(entry_x, entry_y)
            lateral_error = abs(entry_y)
            return distance < 0.3 and lateral_error < 0.2
        elif self.control_mode_ == "RTK_ENTRY" and self.entry_rtk_filtered:
            # RTK判断：距离入口RTK小于0.35m
            boat_east, boat_north, _ = self.get_current_rtk_and_yaw()
            dx = self.entry_rtk_filtered[0] - boat_east
            dy = self.entry_rtk_filtered[1] - boat_north
            distance = math.hypot(dx, dy)
            return distance < 0.35
        return False
    def control_back_in(self):
        """第二阶段：视觉倒入"""
        if not self.last_perception or not self.last_perception['valid']:
            # 视觉丢失，停车
            cmd = Twist()
            self.cmd_pub.publish(cmd)
            return
        # 使用船坞中心位姿控制
        center_x, center_y, center_yaw = self.last_perception['center']
        lateral_error = center_y
        yaw_error = self.normalize_angle(center_yaw - math.pi)  # 倒车目标航向
        cmd_v = -0.02  # 极低速倒车
        cmd_w = self.kp_back_yaw_ * yaw_error + self.kp_back_y_ * lateral_error
        # 限制角速度
        cmd_w = max(-0.04, min(0.04, cmd_w))
        cmd = Twist()
        cmd.linear.x = cmd_v
        cmd.angular.z = cmd_w
        self.cmd_pub.publish(cmd)
    def rate_limit(self, prev, current, max_accel, max_decel):
        """速度变化率限制"""
        delta = current - prev
        if delta > 0:
            return prev + min(delta, max_accel)
        else:
            return prev + max(delta, -max_decel)
