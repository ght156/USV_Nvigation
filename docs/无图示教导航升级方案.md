## 一、需求与约束

| 来源 | 要求 |
|---|---|
| 平台 | 示教模式任意水域可跑（无预制图）；轨迹要直；**严格到点**（点上要执行动作）；要**避障**（否则直接用飞控走点） |
| 船端 | 普通任务/归港走现状有图方案，不受影响 |
| 物理 | 船欠驱动（无侧推），横流下做不到严格压线，目标为"视觉上的直" |

## 二、方案：双模式 Nav2

普通任务/归港 → **MAP 模式**（现状不动）；平台示教任务 → **TEACH 模式**（无图滚动窗，
规划器在环）。Nav2 插件/costmap 结构 configure 期加载、运行时不可改，**切模式 = 用对应参数
文件重启 Nav2 栈**，切换发生在任务之间，数秒重启可接受。

### TEACH 模式要点

- global_costmap：去 static_layer，`rolling_window: true` 100×100 m@0.2 m，挂 voxel layer
  （短 persistence、调高 mark_threshold 防水面 ghost 误绕行），`track_unknown_space: false`；
- 全局帧统一 `odom`，map→odom 恒等静态 TF；
- 每点仍走 NavigateToPose：严格到点、到点停稳、行为树原样；开阔水面规划输出即直线，
  有障碍时 1 Hz 重规划自动绕行（RPP 只会减速/急停，绕障靠规划器）；
- mission_bridge 坐标锚定：TEACH 模式逐点下发时**以当前船位为锚**做经纬度→odom ENU 近似
  （MAP 模式维持 `ref_gnss` 锚转 map 系），做成双模式共用接口；
- 长腿 >100 m 时在 mission_bridge 按窗口半径分段。

### 控制器走直（两模式通用，可独立先调）

1. `rotate_to_heading_min_angle`：0.785 → **0.15~0.2 rad**（起步正对目标再走，跑偏超阈值小修）；
2. RPP 前瞻距适当调小（下限 1.4 m，船头前伸约束），加快横向收敛；
3. 备选：MPPI 控制器（`nav2_mppi_controller`），调参复杂，不作首选；
4. 中间航点 xy 容差 2.0 → 1.0 m（RTK 下可行，减少到点散布）。

## 四、风险与缓解

- 滚动窗 voxel 层水面 ghost → 误绕行：短 persistence + 调高 mark_threshold + raytrace 清障参数
  （`nav2_params_chengfeng.yaml` 注释里有既有经验）；
- 目标超出滚动窗 → 规划失败：长腿分段；示教点距 <<100 m 无影响；
- odom 漂移：TEACH 逐点以当前船位为锚，短腿内漂移可忽略；
- 模式切换回归：切回 MAP 后归港链路（apriltag/docking）必须不受影响。

## 五、验证顺序

1. 岸上录基线：`record_track_data.sh`（现有图模式，15 m 点距）；
2. TEACH 模式开阔水域 15 m / 30 m 点距轨迹对比（gngga vs inspvaa vs odom 三路）；
3. `min_in_place_angular_z=0.15` 验证原地旋转不再倒退；
4. 对齐角 0.15~0.2 + 前瞻调小，验证直线度；
5. 浮筒/岸标障碍，验证 1 Hz 自动绕行；
6. 平台联调：到点动作 → 下一点全流程；模式来回切换回归。
