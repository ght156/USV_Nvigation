## 1. 查看 local_position TF 参数

执行：

```
ros2 param list /mavros/local_position | grep tf
```

然后：

```
ros2 param get /mavros/local_position tf.send
```

如果输出：

```
Boolean value is: False
```

开启：

```
ros2 param set /mavros/local_position tf.send true
```

mavros参数修改：

### 2. 开启 local_position 的 TF

```
ros2 param set /mavros/local_position tf.send true
```

------

### 3. 设置 local_position 发布 `odom -> base_link`

```
ros2 param set /mavros/local_position tf.frame_id odom
ros2 param set /mavros/local_position tf.child_frame_id base_link
```

------

### 4. 验证参数是否修改成功

```
ros2 param get /mavros/local_position tf.send
ros2 param get /mavros/local_position tf.frame_id
ros2 param get /mavros/local_position tf.child_frame_id
ros2 param get /mavros/global_position tf.send
```

应该得到类似：

```
Boolean value is: True
String value is: odom
String value is: base_link
Boolean value is: False
```
