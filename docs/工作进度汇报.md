### 避障调试 —— 两个未闭环问题

1. **局部障碍 vs 全局图对不齐（~1.7-2.2m 系统性偏移）**
   - 实测：local costmap 障碍簇转 map 系后距全局静态障碍 p50=1.67m / p90=2.14m；RTK 固定解（fix_type=4，hdop 0.5），定位链排除。
   - 嫌疑：①静态地图岸线绘制误差（水位变化）；②`ref_gnss_10` 锚点标定误差。
   - **下一步**：船开到地图特征点（码头角）看 RViz 船位是否与地图吻合——船位准=地图绘制问题；船位偏=锚点问题，重校 `ref_gnss_10`。背景见 `docs/地图与GNSS-Nav2对齐说明.md`。
2. **低河岸检测不到**
   - 实测：`min_obstacle_height=-0.25` 每帧切掉 2~20m 内 229 个点（102 个在 8m 内），船 pitch≈-2.4° 时 z 参考（"初始 base_link 水平面"）很脆。
   - **下一步建议**：观测源 `min_obstacle_height` 降到 -0.35~-0.4（水面杂波靠 `mark_threshold=2` 兜，实测压得住）；不行再临时 `mark_threshold` 降 1 验证是否阈值卡掉稀疏岸线点；z>1.0 被 voxel cap 切的点有 153 个/帧（高障碍需求场景也要留意）。

- **船上 build**：`~/usv_nav_ws` 的 install 是 isolated 布局，`--merge-install` 会报错，直接 `colcon build`；本仓归港两包已用 `--symlink-install`（改参数/代码免重 build，重启 launch 即可；切回普通构建需先删 `install/<pkg> build/<pkg>`）。
