# 后端相机 JPEG 压缩转发方案详解

> 面向学习：看懂「为什么要在船上压」「怎么压」「压完怎么在主机显示」。
> 对应代码：`scripts/jzw_compressed_republish/compressed_republish.py`（全文见文末）。

---

## 1. 背景：为什么要压

船上「后端相机」通过 `video_camera` 节点发布**彩色裸图**：

```
/camera_back_video/color/image_raw      sensor_msgs/Image
1920×1080 @ 10fps
```

一张 `1920×1080` 的 RGB 裸图大小：

```
1920 × 1080 × 3 字节 ≈ 6.2 MB/帧
× 10 fps ≈ 62 MB/s
```

主机端（地面站）的 rviz 一旦订阅这条裸图，「船 ↔ 地面」的无线图传链路立刻被抽空，
RTSP 图传延迟能飙到几千毫秒。

而真正有用的 apriltag 输出（TF `dock_frame`、`/apriltag_node/detections`）只有几百字节，
根本不是瓶颈。**元凶纯粹是主机在拉后端裸图抢带宽。**

---

## 2. 思路：就近压缩，别把裸图拉过网

核心一句话：

> **在船上本地**把裸图降采样 + JPEG 压缩，再以 `CompressedImage` 发到一个低带宽话题；
> 主机 rviz 改订这个压缩话题。apriltag 继续在船内订裸图（不跨网），完全不受影响。

好处：

- 带宽从 **~62 MB/s** 降到 **~0.9 MB/s（scale=1.0）** 甚至 **~0.25 MB/s（scale=0.5）**，下降约 70 倍。
- 相机裸图只在船内环流，不给无线链路添堵。
- apriltag 照常在船内订裸图，精度不受压缩影响。

数据流示意：

```
船端（NX, domain=5, CycloneDDS）
  ┌─────────────────────────────────────────────┐
  │ video_camera_node                            │
  │   └─ /camera_back_video/color/image_raw (裸图)│
  │        │                                     │
  │        ├──► (船内) apriltag 节点：订裸图做识别  │
  │        │                                     │
  │        └──► compressed_republish 节点         │
  │              ├─ 降采样 resize                 │
  │              ├─ JPEG imencode                 │
  │              └─ /camera_back_video/color/     │
  │                   image_raw/compressed (压缩) │
  └─────────────────────────────────────────────┘
                        │ 无线链路上只跑压缩流 (~MB/s)
                        ▼
地面站（主机, domain=5, CycloneDDS）
   rviz Image 显示: Topic = /camera_back_video/color/image_raw
                    Transport Hint = compressed   ← 自动解码显示
```

## 3. 消息与 QoS

### 3.1 话题

| 话题 | 类型 | 说明 |
|------|------|------|
| `/camera_back_video/color/image_raw` | `sensor_msgs/Image` | 船上裸图（相机原始，60MB/s） |
| `/camera_back_video/color/image_raw/compressed` | `sensor_msgs/CompressedImage` | 压缩流（默认输出） |
| `/camera_back_video/color/image_small` | `sensor_msgs/Image` | 可选：无压缩插件时给 rviz 的裸图（bgr8/jpeg） |

### 3.2 QoS 为什么必须一致

ROS2 里发布者与订阅者的 QoS 必须**兼容**才能通信：

- 可靠性 `RELIABILITY`：发布者 `RELIABLE`（保证送达）兼容订阅者 `RELIABLE` 或 `BEST_EFFORT`。
- 历史 `HISTORY`：`KEEP_LAST`，深度 5。
- 持久性 `DURABILITY`：`VOLATILE`（只给当前在线的订阅者发）。

代码里订阅相机、发布压缩流都用同一套 QoS：

```python
QoSProfile(
    depth=5,
    reliability=ReliabilityPolicy.RELIABLE,
    history=HistoryPolicy.KEEP_LAST,
    durability=DurabilityPolicy.VOLATILE,
)
```

这样 `ros2 topic hz/echo`、rviz 等默认订阅者都能直接订阅到。
> **实测提醒**：主机端 `ros2 topic hz`/`echo` 能收到 `jpeg`，但如果 rviz 显示不出画面，
> 通常不是 QoS，而是 rviz 里的 **Transport Hint 没设成 `compressed`**（见 §7）。

## 4. 算法原理（逐段拆解）

### 4.1 把 `Image` 转成 `numpy` 的 BGR 矩阵 —— `_to_bgr`

ROS 的 `sensor_msgs/Image` 只是一串字节（`msg.data`），要配合 `height / width / step / encoding` 还原成图像矩阵。

三种常见编码：

```python
def _to_bgr(self, msg: Image):
    enc = msg.encoding
    h, w = msg.height, msg.width
    step = msg.step                     # 每行字节数（可能有对齐填充）
    if enc == "bgr8":
        buf = np.frombuffer(msg.data, dtype=np.uint8).reshape(h, step if step > 0 else w * 3)[:, : w * 3]
        return buf.reshape(h, w, 3)
    if enc == "rgb8":
        # 需要从 RGB 换成 BGR（OpenCV 用 BGR）
        ...
    if enc == "mono8":
        # 灰度图补成三通道
        ...
```

要点：

- `msg.step` 是**一行的字节数**，可能比 `w*3` 大（有内存对齐填充）。所以要先按 `step` reshape 成 `(h, step)`，再切掉尾部填充 `[:, :w*3]`。
- `rgb8` / `mono8` 都要 `cv2.cvtColor` 转成 OpenCV 需要的 `bgr8`（这样后续 resize、编码才统一）。

### 4.2 目标分辨率 —— `_target_size`

两个方式二选一：

- 指定目标宽高：`target_width / target_height` 同时 >0 时直接生效。
- 用缩放比例：`scale=0.5` 则长、宽各乘 0.5（如 `1920×1080 → 960×540`）。

```python
def _target_size(self, w, h):
    if self._tw > 0 and self._th > 0:
        return self._tw, self._th
    nw, nh = int(w * self._scale), int(h * self._scale)
    if nw < 1 or nh < 1:
        return w, h      # 防退化：缩小过头就回退原始尺寸
    return nw, nh
```

### 4.3 降采样 —— `cv2.resize` + `INTER_AREA`

```python
small = cv2.resize(bgr, (nw, nh), interpolation=cv2.INTER_AREA)
```

`INTER_AREA` 是**降采样**（缩小）的最佳插值：它做面积平均，能有效减少锯齿和噪声，缩小时比最近邻/双线性更平滑。

### 4.4 JPEG 编码 —— `cv2.imencode`

```python
ok, jpg = cv2.imencode(".jpg", small, [cv2.IMWRITE_JPEG_QUALITY, self._quality])
```

- `IMWRITE_JPEG_QUALITY`：质量 1~100，**80 是常用均衡点**（人眼几乎看不出差别，体积小很多）。
- 输出 `jpg` 是 `numpy` 数组，用 `jpg.tobytes()` 放进 ROS 消息的 `data` 字段。

### 4.5 打包发布 —— `CompressedImage`

```python
out = CompressedImage()
out.header = msg.header      # 直接复用相机头部（时间戳/frame）
out.format = "jpeg"          # rviz 解码时依据这个字段判断格式
out.data = jpg.tobytes()
self._jpeg_pub.publish(out)
```

`format="jpeg"` 很重要——rviz / image_transport 靠它选 JPEG 解码器。

### 4.6 限帧率 —— `max_fps`

```python
if self._period > 0:
    now = _t.monotonic()
    if self._last is not None and (now - self._last) < self._period:
        return            # 距上一帧太近，丢弃，避免 CPU/带宽浪费
    self._last = now
```

相机本身 10fps，但主机端可能只需要 5~8fps 看画面，限帧能进一步降带宽。

### 4.7 后备裸图 —— `publish_small_image`

当主机**没装** `compressed_image_transport` 插件时，rviz 无法显示 `CompressedImage`。
此时让本节点**多发一路降采样后的裸图**（`Image`），主机直接订它、用默认 raw 显示即可：

```python
if self._small_format == "raw":
    simg.encoding = "bgr8"          # rviz 无插件也能直接显示
    simg.data = small.tobytes()
else:
    simg.encoding = "jpeg"          # 仍走 jpeg，但需要插件
```

## 5. 参数说明

| 参数 | 默认 | 说明 |
|------|------|------|
| `in_topic` | `/camera_back_video/color/image_raw` | 输入裸图话题 |
| `out_topic` | `/camera_back_video/color/image_raw/compressed` | JPEG 压缩输出话题 |
| `jpeg_quality` | `80` | JPEG 质量 1~100 |
| `scale` | `1.0` | 长宽缩放因子（0.5 = 960×540） |
| `target_width` | `0` | >0 则覆盖 scale 直接设输出宽 |
| `target_height` | `0` | >0 则覆盖 scale 直接设输出高 |
| `max_fps` | `0.0` | >0 限帧率，进一步降 CPU/带宽 |
| `publish_small_image` | `false` | 同时发一路给无压缩插件的 rviz |
| `small_topic` | `/camera_back_video/color/image_small` | 上述裸图话题 |
| `small_format` | `raw` | `raw`(bgr8，rviz 可直接显示) 或 `jpeg` |

## 6. 怎么用

### 6.1 船上启动（NX）

```bash
cd ~/jzw_ws/scripts/jzw_compressed_republish
bash run_compressed_republish.sh
```

脚本会自动 `source` ROS、并设：

- `ROS_DOMAIN_ID=5`（船上感知栈所在域，与 `cleaning_boat.launch.py` 一致）
- `RMW_IMPLEMENTATION=rmw_cyclonedds_cpp`

若栈换域，覆盖即可：

```bash
ROS_DOMAIN_ID=5 bash run_compressed_republish.sh
```

带自定义参数（当前实船运行参数）：

```bash
bash run_compressed_republish.sh \
  --ros-args \
  -p in_topic:=/camera_back_video/color/image_raw \
  -p out_topic:=/camera_back_video/color/image_raw/compressed \
  -p scale:=0.5 \
  -p jpeg_quality:=80 \
  -p max_fps:=10.0
```

### 6.2 主机端 rviz 显示

把 rviz 的 **Image 显示**设为：

- **Topic**：`/camera_back_video/color/image_raw`（**基础名，不要带 `/compressed` 后缀**）
- **Transport Hint**：`compressed`

rviz 的 image_transport 会自动去订 `/camera_back_video/color/image_raw/compressed` 并解码显示。

> **不要**在订 `/camera_back_video/color/image_raw`（裸图）——那是 60MB/s 的元凶。
> 主机端一律用压缩话题，带宽降到 MB/s 级，图传不再被抢。

### 6.3 验证带宽

主机端对比（关/开 rviz）：

```bash
ros2 topic hz /camera_back_video/color/image_raw
ros2 topic bw /camera_back_video/color/image_raw
```

跑通后应看到：裸图 `bw` 不再被 rviz 拉高；压缩话题带宽远低于裸图。

## 7. 常见问题排查

### 7.1 rviz 能收到消息但没画面

最常见是**Transport Hint 没设成 `compressed`**，或 **Topic 填成了完整的 `/.../image_raw/compressed`**。

- 正确：`Topic=/camera_back_video/color/image_raw`，`Transport Hint=compressed`
- 错误：`Topic=/camera_back_video/color/image_raw/compressed`（这样 image_transport 会再拼一次 `/compressed`，或按 `Image` 类型找而类型对不上，导致黑屏）

若主机缺 `compressed_image_transport` 插件，给节点加：

```bash
-p publish_small_image:=true
```

然后 rviz 订 `/camera_back_video/color/image_small`（默认 bgr8 裸图，可直接显示）。

### 7.2 主机端完全收不到

依次核对：

```bash
echo $ROS_DOMAIN_ID          # 两边必须一致（当前 = 5）
echo $RMW_IMPLEMENTATION     # 两边一致（当前 = rmw_cyclonedds_cpp）
echo $ROS_LOCALHOST_ONLY     # 实船必须 = 0
ros2 topic list | grep camera
ros2 topic info -v /camera_back_video/color/image_raw/compressed
```

### 7.3 带宽还是大

加 `-p scale:=0.5`（960×540，约 0.25 MB/s）或 `-p max_fps:=5`。

## 8. 实测数据（船上域 5，主机 CycloneDDS）

| 方案 | 尺寸 | 帧率 | 带宽 |
|------|------|------|------|
| 裸图（不让主机订） | 1920×1080 | 10fps | ~62 MB/s |
| `compressed`（scale=1.0, q80） | 1920×1080 | ~9fps | ~0.9 MB/s |
| `compressed`（scale=0.5, q80） | 960×540 | 10fps | ~0.25 MB/s |

## 9. 完整代码

> 以下为当前实际运行版本（`scripts/jzw_compressed_republish/compressed_republish.py`）。

```python
#!/usr/bin/env python3
"""compressed_republish — 船上后端相机裸图 → JPEG 压缩流，供主机端低带宽订阅。

背景：
  cleaning_boat.launch.py（apriltag 容器）里的 video_camera 以
  /camera_back_video/color/image_raw（1920x1080@10fps，约 60MB/s 裸图）发布。
  主机端 rviz 一订阅这条裸图，船↔地面无线链路立刻被抽空，图传(RTSP)延迟暴涨。

本节点在「船上本地」订阅裸图 → 降采样 → JPEG 编码 → 以
  /camera_back_video/color/image_raw/compressed  (sensor_msgs/CompressedImage)
发布。apriltag 仍在船内订阅裸图（不跨网），不受影响；主机端改用压缩流即可，
带宽下降一个数量级，图传不被吃掉。

用法（船上，先 source ROS + 工作区）：
  python3 compressed_republish.py
  python3 compressed_republish.py --ros-args -p in_topic:=/camera_back_video/color/image_raw \
    -p out_topic:=/camera_back_video/color/image_raw/compressed -p scale:=0.5 -p quality:=80

主机端 rviz：把 Image/Camera 显示的 Topic 改成
  /camera_back_video/color/image_raw/compressed
（rviz 用 compressed transport 解码；若主机缺 compressed_image_transport，
  把本节点 publish_small_image:=true，rviz 订 out_topic 的 _small 版裸图即可。）
"""

import math

import cv2
import numpy as np
import rclpy
from rclpy.executors import ExternalShutdownException
from rclpy.node import Node
from rclpy.qos import QoSProfile, ReliabilityPolicy, HistoryPolicy, DurabilityPolicy
from sensor_msgs.msg import CompressedImage, Image


class CompressedRepublish(Node):
    def __init__(self):
        super().__init__("compressed_republish")

        # ── 输入/输出话题 ──
        self.declare_parameter("in_topic", "/camera_back_video/color/image_raw")
        self.declare_parameter("out_topic", "/camera_back_video/color/image_raw/compressed")

        # ── 压缩参数 ──
        self.declare_parameter("jpeg_quality", 80)     # JPEG 质量 1-100
        self.declare_parameter("scale", 1.0)           # 缩放因子（0.5=长宽各减半）
        self.declare_parameter("target_width", 0)      # >0 则覆盖 scale 的宽
        self.declare_parameter("target_height", 0)     # >0 则覆盖 scale 的高
        self.declare_parameter("max_fps", 0.0)         # >0 限帧率，降 CPU/带宽

        # ── 附加：无压缩插件时给 rviz 的降采样裸图 ──
        self.declare_parameter("publish_small_image", False)
        self.declare_parameter("small_topic", "/camera_back_video/color/image_small")
        self.declare_parameter("small_format", "raw")  # raw(bgr8)/jpeg；rviz 无插件时建议 raw

        self._in_topic = str(self.get_parameter("in_topic").value)
        self._out_topic = str(self.get_parameter("out_topic").value)
        self._quality = int(self.get_parameter("jpeg_quality").value)
        self._scale = float(self.get_parameter("scale").value)
        self._tw = int(self.get_parameter("target_width").value)
        self._th = int(self.get_parameter("target_height").value)
        self._max_fps = float(self.get_parameter("max_fps").value)
        self._publish_small = bool(self.get_parameter("publish_small_image").value)
        self._small_topic = str(self.get_parameter("small_topic").value)
        self._small_format = str(self.get_parameter("small_format").value)

        # 订阅：相机发布者 RELIABLE/KEEP_LAST(10)/VOLATILE（apriltag 同款订阅能收到）
        sub_qos = QoSProfile(
            depth=5,
            reliability=ReliabilityPolicy.RELIABLE,
            history=HistoryPolicy.KEEP_LAST,
            durability=DurabilityPolicy.VOLATILE,
        )
        # 发布：默认订阅者(ros2 topic hz/echo、rviz)同为 RELIABLE，避免 QoS 不兼容
        pub_qos = QoSProfile(
            depth=5,
            reliability=ReliabilityPolicy.RELIABLE,
            history=HistoryPolicy.KEEP_LAST,
            durability=DurabilityPolicy.VOLATILE,
        )

        self.create_subscription(Image, self._in_topic, self._on_image, sub_qos)
        self._jpeg_pub = self.create_publisher(CompressedImage, self._out_topic, pub_qos)
        self._small_pub = None
        if self._publish_small:
            self._small_pub = self.create_publisher(Image, self._small_topic, pub_qos)

        # 帧率限流
        self._period = 1.0 / self._max_fps if self._max_fps > 0 else 0.0
        self._last = None
        self._frames = 0
        self._rx = 0
        self._enc = "bgr8"

        self.get_logger().info(
            "compressed_republish 启动：%s -> %s (jpeg q=%d, scale=%.2f%s)"
            % (self._in_topic, self._out_topic, self._quality, self._scale,
               ", fps<=%.1f" % self._max_fps if self._max_fps > 0 else "")
        )
        # 心跳诊断：每 5s 打印一次接收/转发数，便于确认链路活跃
        self.create_timer(5.0, self._diag)

    def _diag(self):
        self.get_logger().info(
            "诊断：收到裸图 %d 帧，已转发 %d 帧" % (self._rx, self._frames)
        )

    def _to_bgr(self, msg: Image):
        enc = msg.encoding
        h, w = msg.height, msg.width
        step = msg.step
        if enc == "bgr8":
            buf = np.frombuffer(msg.data, dtype=np.uint8).reshape(h, step if step > 0 else w * 3)[:, : w * 3]
            return buf.reshape(h, w, 3)
        if enc == "rgb8":
            buf = np.frombuffer(msg.data, dtype=np.uint8).reshape(h, step if step > 0 else w * 3)[:, : w * 3]
            return cv2.cvtColor(buf.reshape(h, w, 3), cv2.COLOR_RGB2BGR)
        if enc == "mono8":
            buf = np.frombuffer(msg.data, dtype=np.uint8).reshape(h, step if step > 0 else w)[:, :w]
            return cv2.cvtColor(buf.reshape(h, w), cv2.COLOR_GRAY2BGR)
        self.get_logger().warn("截获不支持的编码 %s，丢弃" % enc)
        return None

    def _target_size(self, w, h):
        if self._tw > 0 and self._th > 0:
            return self._tw, self._th
        nw, nh = int(w * self._scale), int(h * self._scale)
        if nw < 1 or nh < 1:
            return w, h
        return nw, nh

    def _on_image(self, msg: Image):
        self._rx += 1
        # 可选限帧率
        if self._period > 0:
            import time as _t
            now = _t.monotonic()
            if self._last is not None and (now - self._last) < self._period:
                return
            self._last = now

        bgr = self._to_bgr(msg)
        if bgr is None:
            return
        nw, nh = self._target_size(bgr.shape[1], bgr.shape[0])
        small = cv2.resize(bgr, (nw, nh), interpolation=cv2.INTER_AREA)
        ok, jpg = cv2.imencode(".jpg", small, [cv2.IMWRITE_JPEG_QUALITY, self._quality])
        if not ok:
            return

        out = CompressedImage()
        out.header = msg.header
        out.format = "jpeg"
        out.data = jpg.tobytes()
        self._jpeg_pub.publish(out)

        if self._small_pub is not None:
            simg = Image()
            simg.header = msg.header
            simg.height = nh
            simg.width = nw
            simg.step = nw * 3
            if self._small_format == "raw":
                simg.encoding = "bgr8"
                simg.data = small.tobytes()
            else:
                simg.encoding = "jpeg"
                simg.data = jpg.tobytes()
            self._small_pub.publish(simg)

        self._frames += 1
        if self._frames % 30 == 0:
            self.get_logger().info(
                "已转发 %d 帧 -> %dx%d @ q%d (%.1f KB/帧)" % (
                    self._frames, nw, nh, self._quality, len(out.data) / 1024.0,
                )
            )


def main(args=None):
    rclpy.init(args=args)
    node = CompressedRepublish()
    try:
        rclpy.spin(node)
    except ExternalShutdownException:
        pass
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        # SIGTERM/SIGINT 可能已触发 rclpy 自动 shutdown，重复调用会报错，故忽略
        try:
            rclpy.shutdown()
        except Exception:
            pass


if __name__ == "__main__":
    main()
```
