# 2026-10-07 APPROACH 预备点退化区打转（几何奇异死锁）

> 现象：归港 APPROACH 阶段，船到达预备点附近后原地来回打转 86~120s 不下去，最终超时；进坞后的 ALIGN/BACK_IN/FINAL_DOCK 完全正常。
> 根因：控制律几何奇异 + 旋转扫弧大于换向迟滞，自我维持振荡。
> 状态：已修复（退化区轴对准律 + 卡死逃逸 + 艏向门限放宽）。

## 机理（bag 数据实锤）

预备点退化区：船压在预备线（staging_x）附近、带 0.2~0.5m 横偏时：

1. `dx = staging_x − x ≈ 0`，指向目标点的方位角 `atan2(dy, dx)` 退化为 ±90°，dx 符号一动就翻 180°;
2. 船原地转绕推进器连线（船尾）转，base_link 扫弧实测摆幅 0.68m > 换向迟滞 0.35m——**转艏本身把 dx 顶过零点，方位角翻转，指令反向，自我维持**;
3. 94% 时间 `v=0`（方位差>25° 就不给速度），横向偏差没有收敛渠道 → 只能等超时。

bag 证据（day3_smooth / 复现分析）:

| 证据 | 数值 |
|---|---|
| \|stern_bearing\|>25° 时间占比 | 96% |
| cmd_v=0 时间占比 | 94% |
| e_yaw 振荡 | 均值 38°、周期 ~16s 稳定极限环 |
| dx 变号 | 17 次 |

另：转向响应延迟约 3.2s（延迟互相关 +0.73）——船体惯量与链路延迟叠加，P 增益又全程饱和，构成"带大延迟的 bang-bang"。

## 修复（三件套）

1. **退化区去奇异化**（`docking_motion_controller._compute_approach`):`dist<0.6m`(`approach_degenerate_dist`）时弃用方位角跟踪，改用 BACK_IN 同构轴对准律 `ω=-kyaw·(e_yaw+ky·e_y)`，恒定 0.12 m/s(`approach_degenerate_speed`）蠕行给横向律送行程，y 收敛后 v=0 只修艏向；
2. **卡死逃逸**(FSM `approach_stuck_sec=25s`)：大艏偏持续 25s 无进展主动中止重试，不再干等 120s;
3. **ALIGN 入口艏向放宽** `approach_yaw_tol_deg` 15°→25°：让大艏偏尽早交给有弧线修正能力的 ALIGN。

## 排查套路（以后再遇"到位附近打转"）

1. 拉 bag 看 dock_pose 轨迹：x/y/yaw 是否周期性摆动、v 是否长期为 0;
2. 检查控制律在该几何下是否奇异（指向角、除零、符号翻转）;
3. 检查旋转扫弧幅度 vs 换向迟滞/死区的大小关系；
4. 指令-响应延迟用 IMU 互相关拆（bag 需录 `/mavros/imu/data`，已加入录制清单）。
