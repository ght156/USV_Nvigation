# 电子围栏技术文档：作业区 / 禁航区 / 硬边界

> 内部技术文档：功能定义、实现原理、节点结构、接口与参数、验证方法。
> 面向 Decision/中台的对接契约见 `decision_nav对接文档.md`。

## 1. 功能概述

为 USV 导航栈提供三类区域限制能力，区域由平台（Decision/中台/GCS）以 **WGS84 经纬度** 下发：

| 区域 | 围栏 type | 几何 | 语义 |
|------|-----------|------|------|
| **作业区** | `inclusion` | 多边形（点依次连接，末点自动与首点闭合）或圆形 | 只允许在内部作业；存在多个 inclusion 时**取并集**，船不得驶出并集之外 |
| **禁航区** | `exclusion` | 同上 | 不允许进入；与作业区重叠时**禁航区优先** |
| **硬边界** | —（本平台扩展） | 折线（**不闭合**首末点） | 不允许穿越；栅格化为膨胀粗线挡墙 |

每个围栏带平台分配的 **`fence_id`**，用于日志、违规原因和安全事件关联。

三重生效手段（纵深防御）：

1. **规划层阻挡**：区域栅格化为 Nav2 KeepoutFilter 掩码，全局规划器（SmacPlanner2D）不会规划穿越禁行区的路径；
2. **下发预校验**：`send_waypoints` / `NavigateTask` 收到航点时逐点检查，在作业区外或禁航区内**直接拒绝**（不抢占当前任务，不发布越界事件）；
3. **运行时监控**（对应需求 SAFE-001）：船位越出作业区或闯入禁航区连续确认后**自动急停**，并按有无活动任务分别走 Action Result / 安全事件上报。

## 3. 语义细则

### 3.1 围栏判定规则（`zone_geometry.fence_violation`）

对船位/航点 `(x, y)`（map 系）：

1. 存在 ≥1 个 inclusion 围栏时，点必须在**至少一个** inclusion 内，否则违规（`EXIT`，关联第一个 inclusion 的 fence_id）；
2. 点落入**任一** exclusion 围栏内部，违规（`ENTER`，关联该围栏 fence_id）；
3. exclusion 优先级高于 inclusion：同时位于 inclusion 内和 exclusion 内 → 违规。

### 3.2 掩码生成规则（`zone_geometry.build_fence_mask`）

掩码为与 `/map` 同 width/height/resolution/origin 的 `OccupancyGrid`，值 `100`=禁行（keepout）、`0`=自由：

1. 有 inclusion：**全图置禁行**，再把所有 inclusion 多边形/圆内部填回自由（并集）；
2. 每个 exclusion 内部置禁行（覆盖 inclusion 放行区）；
3. 硬边界折线：相邻点间整数 Bresenham 画线（**不闭合**首末点），每个线上格点加盖 `(2d+1)²` 方形章（`d=boundary_dilation_cells`，默认 2 → 1 m/格时 ±2 m），防止规划器从对角缝隙穿过。

掩码值经 KeepoutFilter（base=0, multiplier=1）映射为致命代价（LETHAL），其后的 `inflation_layer`（半径 3.5 m）自动在禁行区边缘形成代价缓冲。

### 3.3 坐标转换

与 mission_bridge 完全同一约定（`gps_map_conversion.py`）：

- 锚点：`map.yaml` 的 `ref_gnss_10`（[lon, lat]，对应栅格原点 (0,0)）；
- 球面 ENU 近似：`east = R·cos(lat₀)·Δlon`，`north = R·Δlat`（R=6378137 m），小区域误差可忽略；
- ENU → map：按 map.yaml `origin` 的 (ox, oy, yaw) 旋转平移。

因此围栏、航点、map→odom TF（gnss_odom_map_tf）三者的经纬度换算严格一致，不会出现系统性偏移。

## 4. Nav2 KeepoutFilter 接入

- 插件：`nav2_costmap_2d::KeepoutFilter`，加在 global_costmap 的 `plugins` 中 **`inflation_layer` 之前**（`nav2_params_real_mavros.yaml`），local_costmap 不加（滚动窗+odom 系复杂度高，全局规划绕行 + RPP 跟线已够）；
- 订阅：`/keepout_filter/costmap_filter_info`（`nav2_msgs/CostmapFilterInfo`，type=0 keepout，指明掩码话题名）与 `/keepout_filter/keepout_filter_mask`（OccupancyGrid）；
- 两者均 **RELIABLE + TRANSIENT_LOCAL** 发布：costmap 晚启动/重启自动收到最后一帧；区域变更重新发布即热更新，无需重启 Nav2；
- 掩码对齐 `/map`：zone_manager 启动后先订阅 `/map`（latched）拿栅格元信息，围栏可先下发缓存，地图就绪后再栅格化；围栏超出地图范围的部分自动裁掉。

未设置任何围栏时掩码全自由，行为与未装 filter 完全一致（零回归）。

## 5. 持久化

- 每次成功变更（set/clear）经 `atomic_write_json`（临时文件 + rename）写入 **`workspace_nav/json/nav_zones.json`**（参数 `zones_persist_path` 可覆盖）；
- zone_manager 启动时读取并校验该文件，恢复围栏与硬边界并立即发布 `/nav_zones/current`（掩码等 `/map` 就绪后生成）；文件损坏/校验失败则空区域启动并告警；
- 语义：**围栏只有被平台显式覆盖（全量快照）或清除才失效**，重启不掉；
- 注意：持久化文件在源码树内（与 waypoints.json 同一惯例），不入库。

## 6. 节点详述

### 6.1 zone_manager

**服务**（均由本节点提供，命名沿用 mission_bridge 前缀）：

| 服务 | 类型 | 说明 |
|------|------|------|
| `/mission_bridge/set_geofence` | `m_common/srv/SetGeoFence` | 全量围栏快照（开机一次 + 云平台更新时）；空数组=清除全部围栏；校验失败 `success=false` 并**保留旧围栏** |
| `/mission_bridge/get_geofence` | `m_common/srv/GetGeoFence` | 查询当前保存的围栏快照（含 fence_id） |
| `/mission_bridge/set_nav_zones` | `m_common/srv/SetNavZones` | 旧接口兼容：work_area→inclusion(id=`work_area`)、forbidden_zones→exclusion(id=`forbidden_i`) |
| `/mission_bridge/get_nav_zones` | `m_common/srv/GetNavZones` | 旧接口查询；圆形围栏以 16 边形近似返回 |
| `/mission_bridge/clear_nav_zones` | `std_srvs/srv/Trigger` | 清除全部围栏+硬边界 |

**话题**：

- 输入 `/nav_zones`（`std_msgs/String` JSON，GCS 通道）：新格式 `{"fences": [...], "hard_boundaries": [...]}`；兼容旧格式 `work_area`/`forbidden_zones` 键；`{"clear": true}` 清除全部。点支持 `[lon, lat]`、`{"lon":..,"lat":..}`、`{"longitude":..,"latitude":..}` 三种写法；
- 输出 `/nav_zones/current`（String JSON，latched）：当前生效围栏（含 fence_id/type/shape/points/center/radius_m）+ 硬边界，变更时发布，供 mission_bridge 预校验、zone_monitor、GCS 回显。

**校验规则**：多边形 ≥3 个**不重复**点；圆 `radius_m>0`；纬度 [-90,90]、经度 [-180,180] 且有限；`fence_id` 非空且不重复；`type∈{exclusion,inclusion}`、`shape∈{polygon,circle}`。

**参数**：`map_yaml_path`、`map_datum_ref_key`(ref_gnss_10)、`map_topic`(/map)、`filter_info_topic`、`filter_mask_topic`、`zones_input_topic`(/nav_zones)、`zones_current_topic`(/nav_zones/current)、`boundary_dilation_cells`(2)、`republish_period_sec`(0=关闭，TRANSIENT_LOCAL 已够)、`zones_persist_path`。

### 6.2 zone_monitor

- 订阅：odom（`/mavros/gps_input/local`）、`/nav_zones/current`、`/mission_bridge/state`（判断是否 RUNNING/PAUSED）；TF map←odom 由 tf2 查；
- 逻辑：`check_period_sec`(0.5 s) 周期把船位（经 TF 转 map 系）喂给 `fence_violation`；连续 `violation_threshold`(5) 次违规（≈2.5 s 防抖，防 GNSS 抖动误触发）后：
  - 调 `/mission_bridge/emergency_stop` 急停并**锁存**（围栏更新后解除锁存）；
  - **无活动任务**（状态非 RUNNING/PAUSED）时发布 `/mission_bridge/safety_event`（`m_common/msg/NavSafetyEvent`：`event_code=GEOFENCE_VIOLATION`、`fence_id`、`fence_type`、`transition=ENTER/EXIT`、船位经纬度、`distance_to_boundary_m`）；**有活动任务**时不发事件，由 `NavigateTask` Result（`RESULT_GEOFENCE_VIOLATION`）承担上报（mission_bridge 订阅 safety_event 通道获知越界原因，详见对接文档）；
  - 违规条件消失且曾发告警时，补发 `enabled=false`（告警解除）；
- 未设置任何围栏时空转；`enabled` 参数可整体关闭。

### 6.3 mission_bridge 预校验

- 订阅 `/nav_zones/current`（latched），把围栏转成 map 系缓存（`self._zone_fences`）；
- 在 `send_waypoints` / `NavigateTask` Goal 处理中，航点经纬度→map 后**逐点** `fence_violation` 检查，违规即拒绝（中文原因含 fence_id）；
- **拒绝时机在抢占当前任务与写 waypoints.json 之前**，拒绝不产生任何副作用；
- **硬边界不参与预校验**：航点连线穿过硬边界不代表不可达——KeepoutFilter 已把它栅格化为致命代价，规划器会绕端点/缺口找路；只有确实无路时 FollowWaypoints 返回规划失败，经现有失败路径上报。预先拒绝会误杀可绕行的合法任务；
- 无围栏数据时不校验（零回归）。

## 7. 接口定义速查

### 7.1 m_common 定义（可编译）

- `msg/GeoPoint.msg`：`float64 lat, float64 lon`
- `msg/GeoFence.msg`：`string fence_id, string type, string shape, GeoPoint[] points, GeoPoint center, float32 radius_m`
- `srv/SetGeoFence.srv`：`GeoFence[] fences → bool success, string message`
- `srv/GetGeoFence.srv`：`→ bool success, GeoFence[] fences`
- `msg/NavSafetyEvent.msg`：见 §6.2
- 旧接口：`msg/GeoPolygon.msg`、`msg/NavZones.msg`、`srv/SetNavZones.srv`、`srv/GetNavZones.srv`

### 7.2 `/nav_zones` JSON（GCS 通道）

```json
{
  "fences": [
    {"fence_id": "wa1", "type": "inclusion", "shape": "polygon",
     "points": [[120.3680, 31.4862], [120.3700, 31.4862], [120.3700, 31.4878], [120.3680, 31.4878]]},
    {"fence_id": "fz1", "type": "exclusion", "shape": "circle",
     "center": [120.3690, 31.4870], "radius_m": 50.0}
  ],
  "hard_boundaries": [[[120.3680, 31.4870], [120.3700, 31.4870]]]
}
```

### 7.3 调用示例

```bash
# 写入围栏快照
ros2 service call /mission_bridge/set_geofence m_common/srv/SetGeoFence "{
  fences: [
    {fence_id: 'wa1', type: 'inclusion', shape: 'polygon',
     points: [{lat: 31.4862, lon: 120.3680}, {lat: 31.4862, lon: 120.3700},
              {lat: 31.4878, lon: 120.3700}, {lat: 31.4878, lon: 120.3680}]}
  ]}"

ros2 service call /mission_bridge/get_geofence m_common/srv/GetGeoFence
ros2 service call /mission_bridge/clear_nav_zones std_srvs/srv/Trigger
ros2 topic echo --once /nav_zones/current
```

## 9. 测试与验证

- **单元测试**：`test/test_zone_geometry.py` 10 例（点在多边形/圆、inclusion 并集、exclusion 优先、折线不闭合+膨胀、掩码生成）；`python3 -m pytest -p no:anyio test/test_zone_geometry.py`；
- **zone_manager e2e**：发假 `/map` → `set_geofence`（多边形+圆）→ 检查掩码格数与回读 → 非法围栏拒绝且保留旧值 → **重启进程验证持久化恢复** → clear；
- **KeepoutFilter 集成**：standalone 起 global_costmap（实船参数），设禁航区后 costmap 致命格 0→16（4×4m@1m/格 精确吻合）→ 清除回落 0；
- **zone_monitor**：模拟船位在作业区外 → ≈2.5 s 后触发急停 + NavSafetyEvent（fence_id/type/transition 正确）→ 锁存不重复触发；
- 以上临时测试脚本模式见会话记录（/tmp/test_zone_*），实船验证建议按本文 §7.3 下发后 RViz 核掩码、下发越界航点验拒绝、停车漂移验急停。

## 10. 设计取舍与已知限制

- **围栏热更新**：任务执行期间更新围栏立即生效（围栏即代价地图，更安全）；与 Decision 文档"任务内固定用启动时快照"的语义不同，如需严格快照需再改；
- **硬边界**是本平台扩展，Decision 对接文档未覆盖，仅经 `/nav_zones` JSON 或旧接口下发；
- 掩码分辨率 = 地图分辨率（当前 1 m/格），围栏边缘精度 ±0.5 格；inflation 3.5 m 提供缓冲；
- local_costmap 未挂 keepout（全局层已够；船被规划层放行后 RPP 不会主动穿越）；
- 旧接口 `SetNavZones`/`GetNavZones` 兼容保留（自动转围栏，自动分配 fence_id），新链路请用 `SetGeoFence`；
- `PHASE_RECOVERY` / `RESULT_STUCK` 在 NavigateTask 定义中保留但当前实现不上报。
