# 作业区 / 禁止区 / 硬边界（电子围栏）

导航侧已实现三类区域限制，区域由平台以 **WGS84 经纬度点列表** 下发，导航内部转换为 map 系并生效。

## 语义

| 区域 | 几何 | 语义 |
|------|------|------|
| 作业区 `work_area` | 多边形（点依次连接，末点自动与首点闭合） | 只允许在内部作业；区外全部为禁行 |
| 禁止区 `forbidden_zones` | 多边形列表（各自闭合） | 不允许进入；与作业区重叠时禁止区优先 |
| 硬边界 `hard_boundaries` | 折线列表（**不闭合**首末点） | 不允许穿越；栅格化为粗线挡墙 |

## 实现机制

- `zone_manager` 节点（`workspace_nav/zone_manager.py`）接收区域 → 用 `gps_map_conversion`（`ref_gnss_10` 锚点 + ENU）转 map 系 → 栅格化为与 `/map` 同尺寸/分辨率/原点的掩码 → 发布 Nav2 **KeepoutFilter** 的 `CostmapFilterInfo` + `OccupancyGrid` 掩码（TRANSIENT_LOCAL，动态更新即时生效）。
- `nav2_params_real_mavros.yaml` 的 global_costmap 挂了 `nav2_costmap_2d::KeepoutFilter`（排在 `inflation_layer` 之前，禁行区自动被膨胀层缓冲 3.5 m）。
- `mission_bridge` 航点预校验：下发航点在作业区外 / 禁止区内 → `send_waypoints` 直接拒绝（**不抢占当前任务**）。硬边界不做预校验——规划器会自动绕端点/缺口，确实无路时由 Nav2 失败路径上报。
- `zone_monitor` 节点（SAFE-001）：持续检查船位，连续 5 次（≈2.5 s）在作业区外或禁止区内 → 自动调用 `/mission_bridge/emergency_stop` 急停并锁存，区域更新后解除。

## 接口

### Service（decision/中台通道）

| 服务 | 类型 | 说明 |
|------|------|------|
| `/mission_bridge/set_nav_zones` | `m_common/srv/SetNavZones` | 全量设置（覆盖此前全部区域） |
| `/mission_bridge/clear_nav_zones` | `std_srvs/srv/Trigger` | 清除全部区域 |
| `/mission_bridge/get_nav_zones` | `m_common/srv/GetNavZones` | 查询当前生效区域 |

`m_common/msg/NavZones`：`work_area`（GeoPolygon，空=不限制）、`forbidden_zones[]`、`hard_boundaries[]`；`GeoPolygon` 为平行数组 `longitude[]` / `latitude[]`（度）。

### Topic（GCS 通道 + 状态回读）

- 下发 `/nav_zones`（`std_msgs/String`，JSON）：

```json
{
  "work_area": [[lon, lat], [lon, lat], ...],
  "forbidden_zones": [[[lon, lat], ...], ...],
  "hard_boundaries": [[[lon, lat], ...], ...]
}
```

  点也可写成 `{"longitude": .., "latitude": ..}`；`{"clear": true}` 等同清除。

- 回读 `/nav_zones/current`（`std_msgs/String`，JSON，TRANSIENT_LOCAL）：当前生效区域，变更时发布。

### 调用示例

```bash
# 设置作业区（示例点，需替换为实际经纬度）
ros2 service call /mission_bridge/set_nav_zones m_common/srv/SetNavZones "{
  zones: {
    work_area: {longitude: [120.3680, 120.3700, 120.3700, 120.3680],
                latitude:  [31.4862, 31.4862, 31.4878, 31.4878]},
    forbidden_zones: [],
    hard_boundaries: []
  }}"

ros2 service call /mission_bridge/get_nav_zones m_common/srv/GetNavZones
ros2 service call /mission_bridge/clear_nav_zones std_srvs/srv/Trigger
```

## RViz 可视化

添加 Map 显示，话题 `/keepout_filter/keepout_filter_mask`（TRANSIENT_LOCAL），禁行区显示为占用格。

## 参数

见 `config/mission_stack.real_boat.yaml` 的 `zone_manager` / `zone_monitor` 段：

- `zone_manager.boundary_dilation_cells`：硬边界膨胀格数（默认 2，1 m/格 时 ±2 m）
- `zone_manager.republish_period_sec`：掩码周期重发间隔，默认 0（关闭；TRANSIENT_LOCAL 已保证晚加入者收到最后一帧）
- `zone_monitor.enabled` / `check_period_sec`（0.5）/ `violation_threshold`（5）

## 注意

- 区域不持久化：节点重启后需平台重新下发（`get_nav_zones` 可查当前状态）。
- 掩码对齐 `/map`：区域在地图范围外的部分自动裁掉。
- 启动顺序上 zone_manager 会先等 `/map`（map_server 发布），区域可先下发缓存，地图就绪后自动生成掩码。
