# 电子围栏：作业区 / 禁航区 / 硬边界

导航侧已实现区域限制，围栏由平台以 **WGS84 经纬度** 下发，导航内部转换为 map 系并生效。
围栏接口与 decision 对接说明（2026-08-19）§6 对齐。

## 语义

| 围栏 | type | 几何（shape） | 语义 |
|------|------|------|------|
| 作业区 | `inclusion` | `polygon`（点依次连接，末点自动闭合）/ `circle`（圆心+半径） | 船不得驶出；多个 inclusion 取并集 |
| 禁航区 | `exclusion` | 同上 | 船不得进入；与作业区重叠时禁航区优先 |
| 硬边界 | —（本项目扩展，decision 文档未覆盖） | 折线（**不闭合**首末点） | 不可穿越；栅格化为粗线挡墙 |

每个围栏带 `fence_id`（平台分配），用于日志、违规原因和告警关联。

## 实现机制

- `zone_manager` 节点：接收围栏 → `gps_map_conversion`（`ref_gnss_10` 锚点 + ENU）转 map 系 → 栅格化为与 `/map` 对齐的掩码 → 发布 Nav2 **KeepoutFilter** 的 `CostmapFilterInfo` + `OccupancyGrid` 掩码（TRANSIENT_LOCAL，更新即时生效）。
- `nav2_params_real_mavros.yaml` 的 global_costmap 挂了 `nav2_costmap_2d::KeepoutFilter`（在 `inflation_layer` 之前，禁行区自动被膨胀 3.5 m）。
- `mission_bridge` 航点预校验：`send_waypoints` / `NavigateTask` 下发的航点在作业区外或禁航区内 → **直接拒绝**（不抢占当前任务，不发布越界事件）。硬边界不做预校验——规划器自动绕端点，确实无路时由 Nav2 失败路径上报。
- `zone_monitor`（SAFE-001）：连续 5 次（≈2.5 s）检测到船位越界 → 调 `emergency_stop` 急停并锁存（区域更新后解除）；**无活动任务时**另发 `/mission_bridge/safety_event`（`NavSafetyEvent`），有任务时越界由 `NavigateTask` Result（`RESULT_GEOFENCE_VIOLATION`）承担上报。
- **持久化**：每次成功变更原子写入 `workspace_nav/json/nav_zones.json`（可用参数 `zones_persist_path` 覆盖），zone_manager 重启自动恢复；围栏只有被平台**显式覆盖或清除**才失效。

## 接口

### Service（Decision 通道，推荐）

| 服务 | 类型 | 说明 |
|------|------|------|
| `/mission_bridge/set_geofence` | `m_common/srv/SetGeoFence` | 全量围栏快照（开机一次 + 云平台更新时）；空数组=清除全部围栏；校验失败保留旧围栏 |
| `/mission_bridge/get_geofence` | `m_common/srv/GetGeoFence` | 查询当前保存的围栏快照 |

`m_common/msg/GeoFence`：`fence_id` / `type`(exclusion|inclusion) / `shape`(polygon|circle) / `points[]`(GeoPoint lat,lon) / `center` / `radius_m`。

校验规则：多边形 ≥3 个不重复点；圆 `radius_m>0`；经纬度范围合法且有限；`fence_id` 非空且不重复。

### Service（旧接口，兼容保留）

| 服务 | 类型 | 说明 |
|------|------|------|
| `/mission_bridge/set_nav_zones` | `m_common/srv/SetNavZones` | work_area→inclusion、forbidden_zones→exclusion 自动转换（自动分配 fence_id） |
| `/mission_bridge/get_nav_zones` | `m_common/srv/GetNavZones` | 旧格式查询（圆形围栏以 16 边形近似返回） |
| `/mission_bridge/clear_nav_zones` | `std_srvs/srv/Trigger` | 清除全部围栏+硬边界 |

### Topic（GCS 通道 + 状态回读）

- 下发 `/nav_zones`（`std_msgs/String`，JSON）：

```json
{
  "fences": [
    {"fence_id": "wa1", "type": "inclusion", "shape": "polygon",
     "points": [[lon, lat], ...]},
    {"fence_id": "fz1", "type": "exclusion", "shape": "circle",
     "center": [lon, lat], "radius_m": 50.0}
  ],
  "hard_boundaries": [[[lon, lat], ...], ...]
}
```

  点也支持 `{"lon": .., "lat": ..}` 或 `{"longitude": .., "latitude": ..}`；`{"clear": true}` 清除全部。旧格式 `work_area`/`forbidden_zones` 键仍兼容。

- 回读 `/nav_zones/current`（`std_msgs/String`，JSON，TRANSIENT_LOCAL）：当前生效围栏（同上下发格式）+ 硬边界，变更时发布。

### 调用示例

```bash
ros2 service call /mission_bridge/set_geofence m_common/srv/SetGeoFence "{
  fences: [
    {fence_id: 'wa1', type: 'inclusion', shape: 'polygon',
     points: [{lat: 31.4862, lon: 120.3680}, {lat: 31.4862, lon: 120.3700},
              {lat: 31.4878, lon: 120.3700}, {lat: 31.4878, lon: 120.3680}]}
  ]}"

ros2 service call /mission_bridge/get_geofence m_common/srv/GetGeoFence
ros2 service call /mission_bridge/clear_nav_zones std_srvs/srv/Trigger
```

## 参数（`config/mission_stack.real_boat.yaml`）

- `zone_manager.boundary_dilation_cells`：硬边界膨胀格数（默认 2，1 m/格时 ±2 m）
- `zone_manager.republish_period_sec`：掩码周期重发，默认 0（关闭，TRANSIENT_LOCAL 已够用）
- `zone_manager.zones_persist_path`：持久化文件路径，默认 `workspace_nav/json/nav_zones.json`
- `zone_monitor.enabled` / `check_period_sec`（0.5）/ `violation_threshold`（5）

## 注意

- 掩码对齐 `/map`：围栏在地图范围外的部分自动裁掉；zone_manager 先等 `/map`，围栏可先下发缓存。
- 任务执行期间更新围栏：立即对规划生效；越界监控也使用最新围栏（与 decision 文档"任务内固定用启动时快照"不同——本实现里围栏即代价地图，热更新更安全，如需严格快照语义再议）。
