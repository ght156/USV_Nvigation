# 2026-09-30 RS485 驱动 DO 定时关闭误伤背光与无线充电

## 1. 基本信息

- 日期：2026-09-30（夜间归港测试）
- 船：兴飞（`ssh hkzl`，MEC-MB002）
- 包：`~/usv-main/src/usv_rs485_driver`（嵌软维护）
- 现象来源：夜间 dock_only 归港测试连续失败（REACQUIRE_TIMEOUT）

## 2. 现象

夜间归港流程：WAIT_DOCK_OPEN 打开夹爪成功 → APPROACH_ENTRY 途中二维码丢失
→ REACQUIRE_TAG 超时失败，重试 3 次均失败。

## 3. 证据

DO 动作时间线（`~/logs/xingfei_stack/rs485.log`）：

```text
18:37:32 ControlDO 闭合 DO0+DO1（夹爪开），18:37:36 动作完成
18:38:32 整 60 秒，驱动自动 writeDO(0x0000) —— 所有 DO 全清
18:39:06 重试再次 ControlDO … 18:40:07 再次 60s 全清
```

关键事实：`kDOOffMask = 0x0000` 的"自动关闭"是**全通道清零**，不只夹爪线圈——
bit1 背光板、bit2 无线充电一起被断。而 ControlDO 写 `kDOOnMask = 0x0003` 才会
同时点亮背光，自动关闭后**流程里没有任何环节重新点亮背光**（WaitIO 只在
BACK_IN 才运行，APPROACH 阶段背光无人管）。

夜间相机为手动低曝光（解决过曝，见调试文档 §4.5），背光 18:38:32 一灭，
二维码立刻不可见 → REACQUIRE 必然超时。实测验证（18:54）：

| DO 状态 | 相机帧 |
| --- | --- |
| 全断（baseline） | 面板全黑，二维码不可见 |
| `set_do {digital_output: 2}`（bit1） | 面板点亮，二维码清晰可检测 |

DO 位映射（经实物逐一验证）：

| 位 | 硬件 | 说明 |
| --- | --- | --- |
| bit0（掩码 0x0001） | 夹爪电机线圈 | ControlDO 闭合，电机动作 ~3s |
| bit1（掩码 0x0002） | 背光板 | 驱动日志里叫 "DO2"（1 基命名） |
| bit2（掩码 0x0004） | 无线充电启停 | 驱动日志里叫 "DO3"，WaitIO 成功后 BMS RSOC 自动控制 |

## 4. 根因（已确证）

`doCloseTimerCallback()` 的 60 秒定时关闭使用 `writeDO(kDOOffMask=0x0000)`
全通道清零，设计意图是夹爪电机线圈省电，但实现上误伤了同总线的背光板和
无线充电；且 60s 远小于归港流程时长（ACQUIRE~FINAL_DOCK 可达数分钟），
必然在归港途中断电。

业务正确语义（现场要求）：

1. 归港成功前，夹爪不能关、背光必须保持（两者同开同关）；
2. 无线充电（DO3/bit2）归港成功后必须保持，不能被定时器关；
3. 出港以后才允许关。

## 5. 已做修改（船端 `~/usv-main/src/usv_rs485_driver`，已重建生效）

1. `usv_rs485_node.cpp::doCloseTimerCallback()`：自动关闭从
   `writeDO(kDOOffMask)`（全清）改为 `setDOBit(0,false)+setDOBit(1,false)`，
   **只断夹爪线圈和背光，保留 DO3 无线充电**；
2. `usv_rs485_node.hpp`：`kDOAutoCloseDelayMs` 60000 → **600000**
   （10 分钟兜底，远大于单次归港上限 150s；仅作线圈保护，正常流程不再触达）；
3. `usv_rs485_node.cpp` WaitIO 三个退出路径（成功/取消/失败）：关 DO2 改为
   同时关 DO0/DO1——**会话结束才允许夹爪线圈和背光断电**；成功路径维持
   BMS RSOC 接管 DO3 不变。

修改后行为：

| 阶段 | bit0 夹爪 | bit1 背光 | bit2 无线充电 |
| --- | --- | --- | --- |
| ControlDO 打开（归港/出港开始） | 开 | 开 | 不变 |
| 归港途中（APPROACH/BACK_IN） | 保持 | 保持 | 不变 |
| WaitIO 抓住（归港成功） | 关 | 关 | RSOC 接管，保持 |
| WaitIO 取消/失败 | 关 | 关 | 不变 |
| 出港后 10 分钟（兜底） | 关 | 关 | 保持 |

## 6. 待验证 / 下一步

2. 归港成功后确认无线充电上电（RSOC 逻辑）；
